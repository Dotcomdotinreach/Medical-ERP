# MODULE 04 — DOCTOR WORKSTATION (EMR)

You are designing the Doctor Workstation for an Enterprise Medical Management Software.

Authentication, Reception, Emergency and Triage modules are already completed.

DO NOT redesign existing UI.

Reuse every component from the Design System.

Maintain complete visual consistency.

This is NOT a dashboard concept.

This is a complete Electronic Medical Record (EMR) workflow.

Design exactly like Epic Systems, Oracle Health, Cerner Millennium, Meditech Expanse and Apollo Hospitals EMR.

--------------------------------------------------
OBJECTIVE
--------------------------------------------------

Create the complete doctor workflow from selecting a patient until the patient is discharged.

Everything must be connected.

No isolated pages.
